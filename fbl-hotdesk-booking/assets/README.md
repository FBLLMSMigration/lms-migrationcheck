# Logo

`curtin-logo.png` is the file you provided — it's wired up in the
masthead on every page already, so there's nothing to do here.

If Curtin's brand team ever gives you a better version (e.g. an SVG, or
a higher-resolution export), just replace this file with the same name
and it'll pick up automatically. If you use a different filename or
extension, update the `src` in the `<img>` tag in each HTML file's
masthead to match.

If this file is ever missing (e.g. it didn't make it into a deploy),
every page falls back automatically to a plain text "Curtin University"
mark in the same header style, so nothing breaks.
